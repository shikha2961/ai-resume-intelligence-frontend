## AI Resume Intelligence - Frontend
This is the frontend code for the AI Resume Intelligence project. It is built using React and Vite. The main component is `App.jsx`, which renders a welcome message and includes the `ResumeForm` component for users to upload their resumes and receive feedback.

### Getting Started
To run the project locally, follow these steps:
1. Clone the repository:
    ```bash     
    git clone
    ```
2. Navigate to the project directory:
    ```bash
    cd ai-resume-intelligence-frontend
    ```
3. Install the dependencies:
    ```bash
    npm install 
    ```
4. Start the development server:
    ```bash
    npm run dev         
    ```
5. Open your browser and go to `http://localhost:5173` to see the application in action.
